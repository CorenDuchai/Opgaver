# Ubuntu Server 24.04 LTS — Linux 101 CLI Cheat Sheet

## Hostname til opgaven

Brug fx:

    securebase

eller lidt mere tydeligt:

    linux101-securebase

Et "sigende hostname" betyder bare et navn, der fortæller hvad maskinen er til.
Det behøver ikke være smart.

Sæt hostname:

    sudo hostnamectl set-hostname linux101-securebase

Kontrollér:

    hostname
    hostnamectl

## Filer og mapper

    mkdir mappe              # Opret mappe
    mkdir -p a/b/c           # Opret hele mappestrukturen
    touch fil.txt            # Opret tom fil
    cp fil1 fil2             # Kopiér fil
    cp -r mappe1 mappe2      # Kopiér mappe
    mv gammel ny             # Flyt / omdøb
    rm fil                   # Slet fil
    rm -r mappe              # Slet mappe
    cat fil                  # Vis fil
    less fil                 # Vis fil sidevis
    head fil                 # Første linjer
    tail fil                 # Sidste linjer
    tail -f fil              # Følg fil live

## Netplan — statisk IP

Find konfigurationsfil:

    ls /etc/netplan/

Redigér:

    sudo nano /etc/netplan/<fil>.yaml

Eksempel:

    network:
      version: 2
      ethernets:
        eth0:
          dhcp4: false
          addresses:
            - 10.10.10.10/24

Test:

    sudo netplan try

Anvend:

    sudo netplan apply

## Grupper

    sudo groupadd developers
    sudo groupdel developers
    sudo usermod -aG developers axel
    groups axel
    getent group developers

VIGTIGT:
Brug "-aG" når en bruger tilføjes til ekstra grupper.


## Filrettigheder

    ls -l
    chmod 640 fil
    chmod 750 mappe
    chown bruger fil
    chown bruger:gruppe fil
    chgrp gruppe fil

Tal:

    r = read    = 4
    w = write   = 2
    x = execute = 1

    7 = rwx
    6 = rw-
    5 = r-x
    4 = r--
    0 = ---

Eksempel på delt projektmappe:

    sudo chown root:developers /srv/project
    sudo chmod 2770 /srv/project

2 foran 770 = setgid, så nye filer arver gruppen.


## ACL

Installer:

    sudo apt install acl

Se ACL:

    getfacl fil

Giv bruger adgang:

    setfacl -m u:axel:rwx mappe

Fjern adgang:

    setfacl -x u:axel mappe

Standard-ACL:

    setfacl -d -m u:axel:rwx mappe


## SSH

Status:

    systemctl status ssh

Start / stop / restart:

    sudo systemctl start ssh
    sudo systemctl stop ssh
    sudo systemctl restart ssh

Konfiguration:

    sudo nano /etc/ssh/sshd_config

Relevante indstillinger:

    PermitRootLogin no
    PasswordAuthentication no
    PubkeyAuthentication yes

Test konfiguration:

    sudo sshd -t

Restart:

    sudo systemctl restart ssh


## SSH fra klienten

Lav nøgle:

    ssh-keygen

Forbind:

    ssh bruger@10.10.10.10

Med bestemt nøgle:

    ssh -i ~/.ssh/id_ed25519 bruger@10.10.10.10

## Firewall — UFW

    sudo ufw status
    sudo ufw status verbose
    sudo ufw enable
    sudo ufw disable

Standardpolitik:

    sudo ufw default deny incoming
    sudo ufw default allow outgoing

Tillad SSH:

    sudo ufw allow 22/tcp

Kun fra internt subnet:

    sudo ufw allow from 10.10.10.0/24 to any port 22 proto tcp

Se nummererede regler:

    sudo ufw status numbered

Slet regel:

    sudo ufw delete <nummer>

## Linux 101 — huskeregel

Du behøver ikke "kunne Linux" udenad.
Det vigtige er at kunne:

1. finde rundt,
2. forstå hvad en kommando gør,
3. slå syntaks op,
4. dokumentere hvorfor du valgte konfigurationen,
5. verificere resultatet bagefter.
